# History

These documents record how RyoDev started: the original V0 plan (6 Sept 2026),
the demo design review, the publication notes and the real-connection gate.

They are kept for reference and are **superseded** by live mode (hooks → Worker
→ phone), described in the main [README](../../README.md) and
[LIVE-SETUP.md](../LIVE-SETUP.md). The plan's bytes are unchanged; the
deployment tests check its SHA-256.
