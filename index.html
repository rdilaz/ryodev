    About this demo

    All states, assignments, models, accounts, timestamps and usage are invented. Project and machine names are scenario labels, not inspected work.

    Seen is not approved. A finished turn is not a finished project or an accepted release.

    Stale never means offline. Unknown never means idle. Missing values are null, not zero.

    No runtime, provider or billing reads in demo mode. This coding session itself is not zero model usage.
